# Administrator guide

Administrators configure tenants, roles, mission templates, policy envelopes, ArmorIQ connectivity, Google OAuth, provider budgets, queues, schedules, suppression sources, and escalation routing.

Start conservatively: restrict industries and geography, require multiple evidence sources, cap daily contacts and per-domain sends, limit follow-ups, forbid guessed contacts, and keep external Drive sharing denied unless specifically delegated. Verify that production mock modes are rejected. Review policy versions, denials, anomalies, cost, bounce/unsubscribe rates, and audit-chain status regularly.

An operator's mission approval is not reusable authorization for arbitrary actions. Policy expansion, new scopes, new tools, sensitive recipients, and unusual commitments should escalate. Remove access promptly by revoking application role, OAuth grant, ArmorIQ delegation, and active tasks.
