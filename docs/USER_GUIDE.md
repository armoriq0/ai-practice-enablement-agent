# User guide

Create a mission with a measurable outcome, target partner profile, exclusions, timeframe, geographic and industry boundaries, communication limits, meeting constraints, and escalation conditions. Connect the appropriate Workspace account and activate the mission only after its ArmorIQ policy preview passes.

Agents then run autonomously. Use the dashboard to inspect funnel progress, evidence, scores, current plans, outbound activity, replies, booked meetings, costs, and policy decisions. Routine activity does not need approval. Handle only `ESCALATE` outcomes: review the exact action, evidence, uncertainty, and requested authority; then narrow or expand the mission policy, resolve the exceptional case, or deny it.

Pause a mission immediately if targeting is wrong, evidence quality falls, limits are inappropriate, or external activity is unexpected. Unsubscribe, do-not-contact, bounce, or meaningful replies automatically stop sequences.
